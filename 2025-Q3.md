Python Notebook (Generally Available)

- cell magic `%%tsql` or line magic `%tsql` to run T-SQL queries
- integration with lakehouses
- support for NotebookUtils & Semantic link

NotebookUtils new APIs (Generally Available):

- RunMultiple: use `notebookutils.notebook.runMultiple()` to run multiple notebooks in parallel or in a predefined topological order.
- Fastcp: The `notebookutils.fs.fastcp()` provides a more efficient alternative to the traditional `cp` command.
- Notebookutils.notebook CRUD APIs
- Lakehouse utilities: `notebookutils.lakehouse` provides CRUD capabilities for Lakehouse assets such as tables and files.
- Runtime.context.
